MinT không cần key. BYOK key không nằm trong source/repo. Nếu bật “Nhớ key”, key được lưu vào localStorage của origin GitHub Pages trên thiết bị này. Không commit key vào GitHub. Gợi ý AI chỉ được chép vào ô dịch khi bấm “Áp dụng bản dịch”; app không tự publish.
GitHub Pages / bảo mật Wikimedia token
Trang này là static HTML, không chứa Wikimedia token trong source code. Nếu bật “Nhớ token”, access token chỉ được lưu trong localStorage của origin GitHub Pages này trên thiết bị hiện tại. Đừng commit token/client secret vào repository.
